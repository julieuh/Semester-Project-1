# Semester-Project-1
This is a school assignment at Noroff: Semester Project 1. The assignment is to make a website for a community science museum for kids aged 7-15 years old and their families and schools.

This project is part of my frontend development studies and will demonstrates practical implementation of modern web development practices including semantic HTML, modular and responsive CSS as well as accessibility‑focused design. The goal is to build a maintainable and user‑friendly interface while following industry‑aligned standards for layout, and usability only using HTML and CSS.
